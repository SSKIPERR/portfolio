# Фотографии

Положи сюда своё фото с именем **`david.jpg`** — оно автоматически появится
на главной (блок «За каждым пикселем — один человек») и на странице
«Обо мне».

Как добавить через сайт GitHub (30 секунд):

1. Открой эту папку в репозитории на github.com
2. **Add file → Upload files**
3. Перетащи фото, убедись, что имя файла — `david.jpg`
4. Нажми **Commit changes** — через минуту сайт обновится сам

Рекомендации: горизонтальное фото (примерно 1110×683 или любое похожее
соотношение ~16:10), JPG, до ~500 КБ. Пока файла нет, на сайте показывается
аккуратная заглушка — ничего не сломается.
