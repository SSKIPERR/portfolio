# Портфолио — David Margaryan

Личный сайт-портфолио для фриланса в эстетике Apple: крупная типографика,
много воздуха, фирменный синий акцент, полупрозрачная шапка с блюром и
плавные появления при скролле. Светлая и тёмная темы (автоопределение +
переключатель), поиск по сайту (Ctrl/Cmd+K), два языка (RU/EN), полный
адаптив и одна пасхалка 🦆. Чистые HTML/CSS/JS — без сборщиков
и зависимостей.

## Структура

```
index.html      — главная: hero, услуги, fullstack, избранные проекты,
                  процесс, блок «кто за этим стоит», CTA
about.html      — обо мне: тёмная секция с фото, био, стек
projects.html   — все проекты: детальные кейсы с чередующейся раскладкой
contact.html    — контакты: CTA, подсказка «что написать», FAQ
404.html        — страница «не найдено» (GitHub Pages подхватит сам)
css/style.css   — все стили (дизайн-токены в :root наверху файла)
js/main.js      — переводы RU/EN, анимации, мобильное меню
img/            — сюда положи своё фото david.jpg (см. img/README.md)
favicon.svg     — иконка сайта
.github/workflows/deploy-pages.yml — автодеплой на GitHub Pages
```

## Как посмотреть локально

Достаточно открыть `index.html` в браузере. Либо с локальным сервером:

```bash
python3 -m http.server 8000
# или
npx serve .
```

и открыть http://localhost:8000

## Публикация (GitHub Pages)

Сайт публикуется автоматически: workflow
`.github/workflows/deploy-pages.yml` деплоит его на GitHub Pages при каждом
пуше в ветку по умолчанию (а также в `main`, если переедешь на неё).
Адрес сайта: **https://sskiperr.github.io/portfolio/**

Статус деплоя виден во вкладке **Actions** на GitHub. Свой домен
(например `davidmargaryan.dev`) подключается в Settings → Pages.

## Переводы

Все тексты лежат в объекте `I18N` в начале `js/main.js` (ключи `ru` и `en`).
Элементы в HTML помечены атрибутом `data-i18n="ключ"`. Выбранный язык
запоминается в localStorage; по умолчанию берётся язык браузера посетителя.
Переключатели языка — в шапке (EN/RU) и в подвале (English/Русский).
