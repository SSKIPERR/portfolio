# Портфолио — David Margaryan

Личный сайт-портфолио для фриланса: тёмная премиум-тема, два языка (RU/EN),
анимации, адаптив под мобильные. Чистые HTML/CSS/JS — без сборщиков и
зависимостей, поэтому сайт открывается мгновенно и публикуется на GitHub Pages
в пару кликов.

## Структура

```
index.html      — вся разметка (одна страница, секции: hero, обо мне, услуги,
                  навыки, проекты, процесс, контакты)
css/style.css   — все стили (дизайн-токены в :root наверху файла)
js/main.js      — переводы RU/EN, анимации, фильтры, форма
favicon.svg     — иконка сайта
```

## Как посмотреть локально

Достаточно открыть `index.html` в браузере. Либо с локальным сервером:

```bash
# любой вариант
python3 -m http.server 8000
npx serve .
```

и открыть http://localhost:8000

## Как опубликовать на GitHub Pages (бесплатный хостинг)

1. Слей эту ветку в `main` (или работай сразу в `main`).
2. На GitHub открой **Settings → Pages**.
3. В разделе **Build and deployment** выбери: Source — `Deploy from a branch`,
   Branch — `main`, папка — `/ (root)`. Нажми **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://sskiperr.github.io/portfolio/`.

Свой домен (например `davidmargaryan.dev`) подключается там же, в Settings → Pages.

## Форма обратной связи

Кнопка «Отправить» открывает почтовый клиент посетителя с готовым письмом
(mailto) — работает без бэкенда. Если хочешь приём заявок прямо на сайте,
зарегистрируйся на [Formspree](https://formspree.io) (бесплатный тариф),
получи endpoint вида `https://formspree.io/f/xxxxx` и замени обработчик
формы в `js/main.js` на обычный `fetch`-POST на этот адрес.

## Переводы

Все тексты лежат в объекте `I18N` в начале `js/main.js` (ключи `ru` и `en`).
Элементы в HTML помечены атрибутом `data-i18n="ключ"`. Выбранный язык
запоминается в localStorage; по умолчанию берётся язык браузера посетителя.
